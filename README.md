# SAKAN EUROPE — سكن أوروبا

المشروع الجديد المستقل لمنصة عقارية أوروبية للبيع والإيجار.

## التصميم المعتمد
- الصفحة الرئيسية الحالية في `index.html` هي المرجع البصري المعتمد.
- الهوية: أزرق داكن وذهبي.
- اتجاه العربية RTL وخط عربي كلاسيكي، مع خط لاتيني أنيق.
- لا تُعدّل الصفحة الرئيسية أو تعيد تصميمها دون موافقة صريحة.
- المستودع القديم `sakan-app` والدومين المرتبط به خارج نطاق هذا المشروع ويجب عدم تعديلهما.

## الملفات
- `index.html`: الصفحة الرئيسية والواجهة التجريبية.
- `vercel.json`: إعدادات نشر موقع ثابت.
- `tests/validate_site.py`: فحوصات بنية الصفحة والإعدادات.
- `.github/workflows/validate.yml`: تشغيل الفحوصات عند كل تحديث.
- `.gitignore`: ملفات محلية لا ينبغي حفظها في Git.
- `robots.txt`: تعليمات الزحف.
- `sitemap.xml`: خريطة موقع أولية؛ يجب تحديث عنوانها إلى النطاق النهائي قبل إطلاق الموقع.

## الوضع الوظيفي الحالي
الواجهة الحالية نموذج أولي؛ بيانات العقارات والصور والأسعار تجريبية. البحث يرشّح البطاقات الموجودة محليًا فقط، ولا توجد حتى الآن قاعدة بيانات أو تسجيل دخول حقيقي أو حسابات مالكين أو رفع إعلانات أو مدفوعات أو نظام تحقق من العقارات.

## فحوصات
تعمل GitHub Actions على التحقق من البنية الأساسية. نجاح هذه الفحوصات لا يعني اكتمال منصة الإنتاج ولا يغني عن الاختبار اليدوي على الجوال والحاسوب.

## النشر الآمن
لا يُربط أي نطاق حالي بهذا المستودع. بعد اكتمال المراجعة، يُربط المشروع الجديد بمشروع Vercel منفصل، ويُختبر على عنوان معاينة قبل ربط أي نطاق مخصص.
